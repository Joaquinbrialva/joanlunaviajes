A — Campos estructurados

Formulario fijo: asunto, imagen, título, texto, botón. Siempre el mismo esqueleto, solo cambia el contenido. Más simple de usar.

B — Bloques apilables

El admin agrega secciones: imagen, texto, oferta destacada, botón. Más flexible, mails únicos cada vez.

C — Editor rico (WYSIWYG)

Editor tipo Notion/Word: escribís con formato, insertás imágenes inline, ves el resultado al escribir. Más poder, más complejidad.

Mi recomendación: B — bloques apilables. Más flexible que A sin la complejidad de implementar un WYSIWYG completo. El admin puede armar mails diferentes cada vez sin saber HTML.
